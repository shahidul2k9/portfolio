# Shahidul Islam — Portfolio

A static portfolio covering software engineering experience, projects, and research. The site uses HTML, CSS, and JavaScript with no build step.

To preview locally, run `python3 -m http.server 4173 --bind 127.0.0.1` and open http://127.0.0.1:4173/.

The site is designed to publish from the root of the `main` branch with GitHub Pages.
